Verbal Reasoning

Twelve distinct question types appear across the four papers. None of them test general knowledge — every one is a small, learnable puzzle. Spot the type, apply the method.

1. Word-combination analogy Words

Letters taken from the two outer words build the word in brackets. Work out which letters and from where in the first pair, then apply the same rule to the second pair.

Worked example
(cabin [can] net) :: (bacon [?] rope)
Rule found from the first pair: first two letters of word 1 + first letter of word 3 → "ca" + "n" = "can". Apply it: "ba" (bacon) + "r" (rope) = bar.
Another
(moist [mow] wing) :: (cargo [?] rain)
Rule: "mo" (first two of moist) + "w" (first letter of wing) = "mow". Apply it: "ca" (cargo) + "r" (rain) = car.
The exact rule changes every question — sometimes it's last letters, sometimes a mix of positions. Write out the letter positions if it's not obvious in your head.

2. Hidden three-letter word Words

A capitalised word has had three consecutive letters removed. Find the missing three letters so the full word makes sense in the sentence.

Worked example
"The AEMENT was signed by both parties." Insert GRE → AGREEMENT.
Another
"They signed a new CONCT for the building work." Insert TRA → CONTRACT.
Read the sentence for meaning first — it usually tells you roughly what kind of word is missing (a noun? a verb?) before you start testing letters.

3. Letter-pair coding (alphabet shift) Codes

Each letter moves a fixed number of places along the alphabet. Write the alphabet out if needed — counting on fingers under exam pressure causes mistakes.

Worked example
AB is to DE as GH is to (?)
A→D and B→E is a shift of +3. Apply to GH: G+3 = J, H+3 = K → JK.
Another
GOLD is to EMJB as SILK is to (?)
G→E and O→M is a shift of −2 (backwards). Apply to SILK: S−2=Q, I−2=G, L−2=J, K−2=I → QGJI.
A shift can go backwards as well as forwards — check the direction using two letters from the example pair before assuming +1 or +3.

4. Combine two words into a new word Words

Pick one word from each bracketed group so that, joined together, they make a real compound word.

Worked example
(bed, tea, foot) (room, pot, ball) → try each combination: bedroom ✓, teapot ✓, football ✓ — all real words. The multiple-choice options on the answer sheet tell you which specific pair is being tested, so check those first rather than guessing freely.
Another
(sun, rain, tooth) (flower, coat, brush) → sunflower ✓, raincoat ✓, toothbrush ✓ — again more than one combination works in theory. In the real test, only one pairing appears among the five lettered options, so scan the options first and work backwards from there.

5. Move a letter between two words Words

One letter moves from the first word to the second, without rearranging any other letters, to make two new real words.

Worked example
chill → old. Remove c: "chill" − c = "hill". Add it to the front of "old": "cold". Both real words.
Another
beard → an. Remove d: "beard" − d = "bear". Add it to the end of "an": "and". Both real words.
Try removing each letter of the first word in turn and check if what's left is still a real word — that narrows down the candidates fast, before you even look at the second word.

6. Letters standing for numbers Codes

A short key tells you what number each letter is worth. Substitute and calculate using BIDMAS as normal.

Worked example
If M = 6, N = 9, P = 2, work out (M + N) × P.
(6+9) × 2 = 15 × 2 = 30.
Another
If X = 4, Y = 3, Z = 5, work out (X + Z) − Y.
(4+5) − 3 = 9 − 3 = 6.

7. Word-to-code substitution Codes

You're shown a word and its code and must work out the substitution rule, then apply it to a new word. It isn't always a simple alphabet shift — sometimes it's a "mirror": A↔Z, B↔Y, C↔X, and so on (position n swaps with position 27−n).

Worked example
If DOG is coded as WLT using a mirror alphabet (A↔Z, B↔Y…), how is CAT coded?
C (3rd letter) ↔ X (24th). A ↔ Z. T (20th) ↔ G (7th). → XZG.
Another
Using the same mirror alphabet, if BIRD is coded as YRIW, how is FISH coded?
F (6th) ↔ U (21st). I (9th) ↔ R (18th). S (19th) ↔ H (8th). H (8th) ↔ S (19th). → URHS.
Spot the mirror pattern quickly: in a true mirror alphabet, applying the code twice always gets you back to the original letter — that's a good way to check your working.

8. Odd one out / related words Words

Five words are given. Three share a category; find the connection (or find the two that don't belong).

Worked example
CARROT, OAK, POTATO, BEECH, ONION → three are vegetables (carrot, potato, onion); oak and beech are trees.
Try grouping by the obvious category first (living thing, colour, shape) — if that gives you 2 and 3, you've found it. If it gives you 1 and 4, look for a subtler link (all could follow the same word, all rhyme, etc.).

9. Same letter, two gaps Words

The same letter completes the word before the brackets and begins the word after the brackets — and the identical letter must also work for a second, separate pair of words. Test candidate letters against both pairs at once.

Worked example
spo[ ? ]ool    ma[ ? ]op
"spo" + t = "spot", t + "ool" = "tool"; "ma" + t = "mat", t + "op" = "top". The letter t works for both pairs.
Another
bea[ ? ]ear    spi[ ? ]ame
"bea" + n = "bean", n + "ear" = "near"; "spi" + n = "spin", n + "ame" = "name". The letter n works for both pairs.
Start with the pair that has fewer plausible letters (a less common ending is easier to narrow down), then test only those candidates against the second pair.

10. Number series Codes

The same "find the rule" approach as maths sequences, but appearing among the verbal reasoning questions — don't assume it's always a straightforward addition.

Worked example
5, 9, 13, 17, ?
Each term adds 4: 21.
Another
2, 6, 18, 54, ?
Each term is multiplied by 3, not added to: 54 × 3 = 162.

11. Closest in meaning Words

Pick the single word from the options that means most nearly the same as the word given. The wrong options are usually related in topic but not in actual meaning.

Worked example
Which word is closest in meaning to RELUCTANT?
A) eager   B) unwilling   C) tired   D) confused   E) brave
"Eager" is the opposite; "tired", "confused" and "brave" are all plausible-sounding but unrelated in meaning. The answer is B) unwilling.
Say the word to yourself in a simple sentence first ("He was reluctant to go" = "He didn't want to go") — it's often easier to match a meaning you've put in your own words than to compare five options directly.

12. Logical deduction Logic

You're given a set of true statements and must work out which conclusion must follow — not just which one sounds plausible.

Worked example
Every student in Class 5 plays either football or chess, but not both. 18 students play football. 7 students play chess. Which of these must also be true?
A) Some students play both   B) There are 25 students in Class 5   C) More students play chess than football   D) No students play any sport   E) Class 5 has exactly 18 students
Since every student plays exactly one of the two (never both, never neither), the total is simply 18 + 7 = 25. The answer is B.
Underline the absolute words in the statements — "either…or", "but not both", "every", "none" — these are what let you deduce a certain conclusion rather than just a likely one.
